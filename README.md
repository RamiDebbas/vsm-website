# VSM — website

Interactive single-page site for **VSM** (legal entity VSM GROUP INC) and its seven divisions: Music, Events, Talent,
Growth, Consulting, Investments and Development.

**Concept — "The Orrery":** the hero *is* the logo, live in 3D. The gold VSM word is orbited by seven white and
gold rings, one per division, each carrying its division's planet. Choosing a division (dial, index, planet, or a
`#music`-style link) retints the whole page, brings its planet forward and pre-addresses an enquiry email to it.

Address: **https://vsmgrp.com**, hosted free on GitHub Pages (setup: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)).

Static site · Vite + TypeScript + three.js · no backend · no third-party requests · strict CSP.

## Quick start

```bash
npm ci
npm run dev        # http://localhost:5173
npm run check      # typecheck + tests + production build + dist/ inspection
```

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server with hot reload |
| `npm run typecheck` | Browser, Node (build) and test TypeScript projects |
| `npm test` | Unit + structural tests (Vitest, jsdom) |
| `npm run build` | Production build into `dist/`, then `scripts/verify-dist.mjs` inspects it |
| `npm run preview` | Serve the production build locally |
| `npm run logo` | Regenerate all logo concepts from the parametric generator |
| `npm run brand` | Regenerate favicons / share image / manifest icons from `src/brand/*.svg` |
| `npm run cards` | Business cards → print-ready PDFs + QR scan test ([brand/cards/README.md](brand/cards/README.md)) |

## Where things live

| Change… | Edit |
| --- | --- |
| Company facts, divisions, colours, email, phone | [`src/config/site.ts`](src/config/site.ts) — the single source of truth |
| Logo | [`brand/README.md`](brand/README.md) — generated by `npm run logo`, installed with `npm run brand` |
| Copy / page structure | [`src/ui/markup.ts`](src/ui/markup.ts) |
| Look & feel | [`src/styles/tokens.css`](src/styles/tokens.css) first, then `base.css` / `sections.css` |
| 3D scene | [`src/scene/`](src/scene) — camera choreography in `poses.ts` |
| Security headers / CSP | [`src/config/security.ts`](src/config/security.ts) |
